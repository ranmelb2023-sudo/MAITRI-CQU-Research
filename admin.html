MAITRI Content Administration

This is the starter administration page for the project.

Current version: the public website reads its content from data/content.json. Edit that file and redeploy the site to publish changes.
Next stage: when you want a real login-based admin dashboard, connect this page to Supabase. Do not put a Supabase service-role key in browser code.

  • Research objectives
  • Methodology
